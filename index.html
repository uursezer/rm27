RetouchX Plugin — 40 portraits, one pass

Every frame comes back as a before and after you can step through, so nothing leaves the machine unseen. The queue writes a sidecar next to each original rather than touching the file itself, which means a pass can be undone a week later without hunting for a backup. Presets applied by the queue are the same presets you would apply by hand — there is no second, secret set of settings for batch work — so a frame you fix afterwards and a frame the queue fixed land in the same place. Failures are reported per file with the reason next to them: a raw the decoder does not know, a layered file that would have to be flattened, a frame with no face in it. Nothing is skipped quietly. The whole run is logged, and the log is a text file you can read.

Keeping skin texture

One pass over a full gallery: skin, teeth and eyes are evened out on every frame while the grain stays exactly where it was.

1:33
Reviewing before export

The smoothing runs under the texture rather than over it, so pores survive at 100%. Frequency separation is done per-frame rather than once for the set, which is what keeps a bride lit by a window and a groom lit by a lamp from ending up with the same skin.

1:57
Masking hair edges

Edge detection keeps the flyaway strands rather than painting them into the background. It works on the alpha it builds from the frame rather than on a hard selection, so a strand that crosses a bright window and a dark suit in the same photograph stays a strand in both. Hair against a busy background is the case that breaks most tools, and it is the case this one was cut on: backlit ceremonies, veils over dark jackets, curls against foliage. The mask is generated at full resolution and kept, so the same frame re-run a month later gives the same result rather than a slightly different one. Where it is not sure, it says so — the frame comes back flagged with the region it could not resolve, rather than confidently wrong. You can paint a correction in and the correction is remembered for the rest of the run, which is usually enough to carry a whole set shot in the same light. None of this runs in the cloud: the files stay on your machine, and the machine does not need to be online.
